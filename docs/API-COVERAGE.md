## Verification policy

Do not call the full Avalonia capability work complete while this matrix has missing required APIs or incomplete required interaction/lifetime coverage. A native smoke in Linux/Xvfb does not prove Windows/macOS behavior. Timing fixtures exclude native/GPU drawing; MyGo's CPU rendering fixture must not be directly ranked against them.
