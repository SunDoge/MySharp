# Avalonia capability coverage

This matrix distinguishes an implemented path from convenience coverage and native/platform verification. Access to raw APIs is not evidence that every interaction has been tested.

| Capability | Implemented path | Evidence / remaining work |
| --- | --- | --- |
| Existing / third-party controls | Ui.Control<T>(factory) or new()-constrained overload; create once per identity | Factory, retained native input and event-lifetime tests. Third-party packages are supplied by the application. |
| Parent-sensitive native controls | Ui.Direct<T>; no extra Border | GridSplitter's real Grid parent and column are verified. Dragging still needs native input coverage. |
| Properties, bindings, events | Set for native properties, SetOuter for outer/attached properties; On routed events; OnChanged property changes; Configure/Native escape hatch | Current callbacks replace old callbacks, no duplicate subscriptions, omission detaches, build-time changes do not loop into input handlers. Native Avalonia Binding/CompiledBinding remains accessible via Configure; full binding matrix not yet exercised. |

## Verification policy

Do not call the full Avalonia capability work complete while this matrix has missing required APIs or incomplete required interaction/lifetime coverage. A native smoke in Linux/Xvfb does not prove Windows/macOS behavior. Timing fixtures exclude native/GPU drawing; MyGo's CPU rendering fixture must not be directly ranked against them.
