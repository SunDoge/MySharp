# Internationalization

MySharp's `I18n` service uses .NET `ResourceManager` / `.resx` and `CultureInfo`.
Applications own the service and translation resources. No localization package,
XAML, global singleton, or background refresh loop is required.

```csharp
// Create once, owned by the application; dispose after its views are disposed.
var translations = new I18n(
    new ResourceManager("MyApp.Localization.Strings", typeof(App).Assembly),
    CultureInfo.GetCultureInfo("en-US"));

void Build(UiContext cx)
{
    var t = cx.UseI18n(translations);
    Ui.Column(cx).Set(Visual.FlowDirectionProperty, t.FlowDirection).Children(() =>
    {
        Ui.Text(cx, t["settings.title"]);
        Ui.Text(cx, t.Format("balance", 12345.67m));
        Ui.Text(cx, t.Plural("process.count", 2));
        Ui.Button(cx, "简体中文").OnClick(() =>
            t.Culture = CultureInfo.GetCultureInfo("zh-CN"));
    });
}
```

Add `using System.Globalization;`, `using System.Resources;`, `using Avalonia;`,
and `using MySharp;`. The resource basename uses the project's **RootNamespace**
and resource directory, not necessarily the assembly name. The Gallery's example
is `MySharp.examples.Workspace.Localization.Strings`.

For an SDK project, `.resx` files are normally embedded automatically:

```text
Localization/Strings.resx          default strings
Localization/Strings.zh-CN.resx    Simplified Chinese
Localization/Strings.ja.resx       Japanese
```

`ResourceManager` performs normal culture-parent/default-resource fallback. A key
missing even from the default resources displays its key, writes a debug diagnostic,
and raises `MissingTranslation(key, culture)` once per key per culture selection.
A misconfigured resource basename still throws: it is a configuration error.
Empty translations are valid. Values such as `balance` can use composite formats
like `Balance: {0:N2}`. Invalid format strings also throw instead of silently hiding
translation errors.

`Culture` is a read-only snapshot of the supplied culture. Change it on the UI
thread, as with `State<T>`. Background callers can use
`Dispatcher.UIThread.InvokeAsync(() => translations.Culture = culture)`.
The service does not mutate `CurrentCulture`, `CurrentUICulture`, or thread defaults;
format through `t.Format` to use the selected culture. It does not automatically
select or persist the user's preferred language.

Reads subscribe the building view, including reads through the indexer or `Format`.
`UseI18n(service)` also subscribes explicitly when only passing the service along.
Switching language schedules a normal retained rebuild, preserving native controls,
input drafts, caret, focus, and application state when their identities stay stable.
Views unsubscribe on disposal. Applications must rebuild externally retained native
subviews themselves if those subviews do not read this observable during a MySharp
build. Do not change identities or use translated text as list keys.

RTL is explicit: apply `t.FlowDirection` to the appropriate container using the
inherited Avalonia property, as above. This avoids forcing an entire window or a
mixed-language embedded example into a different direction. Real Arabic/Hebrew
layout and screen-reader behavior still need platform testing.

## Plurals

Define `process.count.one` and `process.count.other` in the default resources, with
formats such as `{0} process` and `{0} processes`. `Plural(key, decimalCount)` chooses
the suffix and formats the count as argument zero.

Built-in rules cover English (one/other, including visible fractional digits) and
Chinese/Japanese/Korean (other). Other languages throw `NotSupportedException` when
`Plural` is used, rather than silently applying English rules. Supply a category
resolver for other languages (e.g. backed by a CLDR library):

```csharp
new I18n(resources, culture, pluralCategory: (count, culture) =>
    YourPluralRules.SelectCategory(count, culture));
```

The category can be zero/one/two/few/many/other as required by the application.
The service is not a complete ICU MessageFormat or CLDR implementation. Select
messages and gender/agreement are application responsibilities. A custom
`Func<string, CultureInfo, string?>` lookup can replace ResourceManager for JSON
or other storage; that provider is responsible for its own fallback.

## Gallery and verification

`dotnet run -- --page=settings` exposes English/简体中文 switching for Settings and
Gallery navigation. The other page bodies, including 2048 and Pulse, remain English.
The selection and edited preferences are session-only.

The framework tests cover real satellite resource loading, default fallback,
missing diagnostics, formatting, culture immutability, plural/provider injection,
RTL metadata, shared consumers, no global culture mutation, disposal, and retained
editor/focus/caret/draft across language changes.
