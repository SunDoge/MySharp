# Changelog

## 0.1.0-preview.1

Initial GitHub source preview. NuGet.org publication is a separate step.

- Pure C# retained Avalonia UI declarations, automatic caller-site identity and keyed scopes.
- Native controls, layouts, themes, windows, input, popups, owned templates and platform services.
- Shared/local state, cancellable tasks, UI-thread work and deterministic resource ownership.
- Optional best-effort .NET Hot Reload helper, without changes to core rebuild/drawing paths.
- Standalone compact C# formatter, four-page sample, profiling/reproduction scripts and behavior tests.

Targets .NET 10 / Avalonia 12.1.4. APIs may change during preview. Native validation currently covers Linux X11; broader platform coverage, stable arbitrary-edit state migration and full Avalonia convenience coverage remain incomplete.
